Verification can't run — WebAssembly is disabled

This site checks your browser using WebAssembly (WASM), and your browser has it turned off or blocked, so the check can't finish. WASM is required — enable it and reload:

  • Firefox — open about:config, search javascript.options.wasm, set it to true, then reload.
  • Chrome / Edge / Brave / Opera — WebAssembly is on by default and there's no simple settings toggle. If you turned it off yourself, it was a launch flag — remove --js-flags=--noexpose_wasm (or --jitless) from your browser shortcut / launch command and relaunch. In chrome://flags, also reset any WebAssembly experiments to Default. Otherwise a content-blocker (NoScript, uBlock in advanced mode) or an enterprise policy is blocking it — allow scripts / WebAssembly for this site.
  • iPhone, iPad or Mac with Lockdown Mode — Apple's Lockdown Mode disables WebAssembly. In Safari, tap AA at the left of the address bar → Website Settings and switch Lockdown Mode off for this website (or turn it off entirely under Settings → Privacy & Security → Lockdown Mode), then reload.
  • GrapheneOS (Vanadium browser) — Vanadium disables JavaScript JIT by default; recent versions still run WASM through a built-in interpreter, but if this keeps failing, open the ⋮ menu → Site settings and enable JavaScript JIT for this site, then reload.

Once WebAssembly is enabled, this page verifies automatically. No WASM, no access — it's not optional here.
